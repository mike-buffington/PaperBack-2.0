# PaperBack 2.0 for macOS

Native macOS PaperBack-compatible backup encoder and decoder. Uses the source code from Oleh Yuschuk's **PaperBack** (https://www.ollydbg.de/Paperbak/index.html).


- Generate PNG or BMP backups using single-page or multi-page layouts.
- Choose paper-based layouts or columns-and-rows options.
- Restore supported PNG and BMP backups.
- Create and restore password-encrypted backups using the original format.
- Updated About PaperBack attribution with a clickable link to the original project.

**Installation:** Download `PaperBack-2.0-macOS.zip`, extract `PaperBack.app`, and move it to Applications. This is an unsigned local build unless separately signed and notarized.
